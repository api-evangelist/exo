# Exo (Exo Imaging, Inc.)

> Exo is a Santa Clara, California medical imaging company building a handheld ultrasound ecosystem for point-of-care ultrasound (POCUS). Its silicon-based Exo Iris handheld probe pairs FDA-cleared, on-device AI with Exo Works, an AWS-hosted POCUS workflow, documentation, billing, QA and credentialing platform. **Exo publishes no public developer API, OpenAPI specification, SDK, or developer portal.** Its documented integration surface is a DICOM and HL7 interface engine for hospital IT, available on the Exo Works Enterprise tier.

This file was generated by API Evangelist from Exo's public surface. It is not published by Exo. Exo serves no llms.txt of its own (https://www.exo.inc/llms.txt returns 404).

## Products

- [Exo Iris](https://www.exo.inc/iris): handheld ultrasound probe with on-device AI; tech specs at https://www.exo.inc/iris/specs
- [Exo Works](https://www.exo.inc/exo-works): POCUS workflow, documentation, QA, credentialing and billing platform; tech specs at https://www.exo.inc/exo-works/specs
- [Exo AI / SweepAI](https://www.exo.inc/ai): FDA-cleared ultrasound AI applications
- [Exo technology](https://www.exo.inc/technology): silicon (pMUT) ultrasound platform

## Integration surface

- DICOM: works with any DICOM-enabled ultrasound; DICOM modality worklist; send/store to PACS or VNA; TLS-secured DICOM transport
- HL7 (Exo Works Enterprise): ADT (admit/discharge/transfer), ultrasound orders, exam results/report
- FHIR: listed as part of "EHR integration (HL7/ADT/FHIR)" on the Exo Works Enterprise tier; no FHIR endpoint or capability statement is published
- EHR programs: Epic App Orchard certified; Oracle Cerner CODE program approved
- Authentication: SAML single sign-on; Active Directory (LDAP) on Enterprise; RBAC; MFA and device biometrics on Iris
- No public REST/GraphQL API, no OpenAPI, no webhooks, no MCP server, no A2A agent card
